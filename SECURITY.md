# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub's
[private vulnerability reporting](https://github.com/ChaoticMischief/game1/security/advisories/new)
(Security tab → "Report a vulnerability").

Include what you found, how to reproduce it, and the affected build version (shown in-game and
in `Application.version`, e.g. `0.1.0.2026.09.28.1a2b3c4d`).

You can expect an acknowledgement within a week. This is a small project without a bug bounty.

## Scope

- The game's code and builds from this repository.
- The repository's automation: GitHub Actions workflows, git hooks and agent hooks.

Leaked credentials count too: if you see a secret committed anywhere in this repository or its
history, please report it the same way.
