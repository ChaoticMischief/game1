# Documentation

| Folder | What goes there |
|---|---|
| [`design/`](design/) | Game design: concept, pillars, mechanics, levels, story, art and audio direction. Living documents, updated as the game changes. |
| [`adr/`](adr/) | Architecture decision records: one short, numbered file per significant technical decision, recording the context and why. Never rewritten; superseded by a newer record instead. |

Code-level documentation lives next to the code (XML doc comments, `README.md` in a folder where
it helps). How to work in this repo is in [`AGENTS.md`](../AGENTS.md) (all contributors, human or
AI) and [`CONTRIBUTING.md`](../CONTRIBUTING.md).

Design documents describe game content, which is all rights reserved like the rest of the game's
content (see [`CONTENT-LICENSE.md`](../CONTENT-LICENSE.md)).
