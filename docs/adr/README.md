# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order. Each records the context, the
decision, and its consequences, so later contributors (and agents) know *why* things are the way
they are. Don't edit an accepted record to change the decision; add a new one that supersedes it
and mark the old one "Superseded by NNNN".

Template:

```markdown
# NNNN. Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context
What forces are at play; what problem needs deciding.

## Decision
What we decided.

## Consequences
What becomes easier or harder; follow-up work.
```
