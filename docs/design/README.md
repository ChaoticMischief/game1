# Game design

The game design lives here, split by topic rather than in one large document, so each piece can
be updated and reviewed on its own. Start with `overview.md` once the concept is settled.

Suggested files as the design grows:

| File | Contents |
|---|---|
| `overview.md` | Elevator pitch, genre, target platforms and audience, design pillars |
| `core-loop.md` | What the player does minute to minute, and why it's fun |
| `mechanics/<name>.md` | One file per mechanic or system: rules, tuning values, edge cases |
| `levels/<name>.md` | Level or area layouts, goals, pacing |
| `narrative.md` | Setting, characters, story beats |
| `art-direction.md`, `audio-direction.md` | Style references and constraints |
| `backlog.md` | Ideas not yet scheduled (scheduled work is in GitHub Issues) |

Link issues to the design section they implement, and update the design doc in the same PR when
an implementation changes the design.
